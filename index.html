Current Project: Sky Runner

Sky Runner — Browser Endless Runner

An endless runner built with plain HTML5 canvas and JavaScript, in the spirit of the classic offline browser dinosaur game. Jump over colorful obstacles, chase a high score, and use rewarded video ads for revives and extra lives when you're close to a personal best.

How It Was Built

Sky Runner runs on a single self-contained HTML file — no build tools, no frameworks, just vanilla JavaScript drawing to an HTML5 canvas element at roughly 60 frames per second. Physics for jumping and gravity are handled with simple velocity math, obstacles spawn on a timer that gradually shortens as your score climbs, and your best score is saved locally in your browser so it persists between visits without any server or account needed.

The entire project was developed and deployed from a phone, using Termux (a Linux terminal environment for Android) for git and file operations, with the game itself written and edited directly in a mobile text editor.

FAQ

Do I need to download anything to play?
No — it runs entirely in your browser, no install required.

Is my score saved?
Your best score is saved locally in your own browser. It isn't sent anywhere or tied to an account.

What are the rewarded ads for?
Watching a short video ad lets you revive after dying or bank an extra life, up to five uses per run. It's entirely optional — you can always just start a new game instead.

Will there be more games?
Yes — this site will be updated as new small projects are finished. Check the devlog for progress notes.
